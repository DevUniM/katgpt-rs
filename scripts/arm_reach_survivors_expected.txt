# Mutants that SURVIVE every arm, pinned by MEMBERSHIP with a reason per row
# (Issue 790 T2). Read by `scripts/arm_reach_gate.py`.
#
# Format, 2+ whitespace-separated fields, plus a verified source-line comment:
#
#   <module>::<function>::<op-token>::<digest>#<n>   <reason>   #= <source line>
#
# The reason is REQUIRED and the parser refuses a row without one. The `#= `
# comment is VERIFIED against the observed line on every run — the key carries
# an unreadable digest, so the comment is the only part of this file a human
# adjudicates from, and a comment nothing can red is a comment that drifts into
# a lie.
#
# ── the key is LINE-FREE, on purpose ────────────────────────────────────────
# A line NUMBER drifts on every edit above it, so a line-numbered pin file reds
# on commits that changed nothing about it — and a pin file that reds on noise
# is one people delete. The digest is over the stripped source TEXT and the
# `#<n>` ordinal is scoped to the WHOLE address, so adding a new mutation site
# to a function renumbers nothing. Only genuinely DUPLICATE line text shares a
# sequence; there are two such rows below and both are real.
#
# ── reds in BOTH directions ─────────────────────────────────────────────────
# A new UNPINNED survivor is a finding. A pinned row an arm now reaches is a
# finding too — the row and the repair belong in the same commit. A count would
# be green on the swap.
#
# ⛔ THE DEFAULT IS TO CLOSE THE GAP, NOT TO ADD A ROW. Writing the reason IS
# the adjudication: T2 set out to pin 47 rows that T3 had characterised as
# EQUIVALENT / I-O / formatting, and could not write a true sentence for about
# a third of them. They were plain functions over plain data and they are armed
# now — 47 down to the rows below, `bench_doc_audit` alone 23 -> 3. A row whose
# reason is "not written yet" is a backlog wearing a pin, which Issue 785
# forbids; if you cannot state WHY no arm should reach a line, write the arm.
#
# Three classes qualify, and each row says which it is:
#   EQUIVALENT  the mutant cannot change any output — with the argument, not
#               the assertion. "It looked fine" is not a reason.
#   I/O SHELL   reaching it means spawning the auditor or the cargo/git child
#               that produces its input, inside the arm that reads it.
#   CROSS-MODULE the rule IS asserted, by a different module's arm. Reach is
#               measured per module, so this reads SURVIVED (Issue 755).
