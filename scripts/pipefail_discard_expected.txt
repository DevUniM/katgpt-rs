# Findings pinned by MEMBERSHIP with a REQUIRED reason per row.
# Read by scripts/pipefail_discard_drift_sweep.py.
#
# Format, one row, 3 whitespace-separated parts:
#
#   <repo>:<relpath>:<8-hex sha256 of the stripped line text>#<ordinal>
#     <REASON — why this row exists instead of the fix>
#     #= <the source line the digest was taken from>
#
# The key is LINE-FREE on purpose (arm_reach_survivors_expected precedent):
# a line NUMBER drifts on every edit above it, so a line-numbered pin file
# reds on commits that changed nothing and gets deleted. The ordinal is
# scoped to the whole (repo, rel, digest) address; only genuinely duplicate
# line text shares an address.
#
# The `#=` comment is VERIFIED against the measured line on every run — the
# digest is unreadable, so the comment is the only part of this file a human
# adjudicates from, and a comment nothing can red drifts into a lie.
#
# ── reds in BOTH directions ──────────────────────────────────────────────────
# A new UNPINNED finding is a finding. A pinned row that no longer fires is
# a finding too — the row and the repair belong in the same commit. A count
# would be green on the swap.
#
# ⛔ THE DEFAULT IS TO FIX THE SITE, NOT TO ADD A ROW. Two row classes exist
# here, and each row says which it is:
#   DELIBERATE TRIPWIRE  the death IS the assert (the proof_gate family:
#                        an axiom-free proof must fail loud). Re-home the
#                        assert, then drop the row in that commit.
#   LIVE KILL-SHAPE      an unexamined instance of the class — the script
#                        dies before its own output/report (the
#                        perf_rematch damage shape). The repair is one
#                        neutralizer (`|| true` at the substitution tail or
#                        a trailing `|| cmd`); drop the row in that commit.
