# Sweeps deliberately NOT calling a FAMILY-WIDE MECHANISM — Issues 797 T5, 824.
#
# One row per (mechanism, sweep): `<mechanism> <sweep>  # reason`.
# A reasonless row is REFUSED, an unknown mechanism slug is REFUSED, and a row
# whose sweep has since been wired REDS: a pin file that only ever loosens is a
# backlog wearing a pin (Issue 785).
#
# Mechanisms (the live set is `MECHANISMS` in the gate — this list is prose):
#   worktree-advisory       sweep_advisory() / worktree_advisory()  (Issue 797)
#   known-extra-exemption   pin_row_exempt()                        (Issue 815/821)
#   head-provenance         head_delta() / head_overlay() / head_tree() /
#                           head_text()                             (Issue 822)
#
# ⛔ The row is QUALIFIED by mechanism, and that is not bookkeeping. A bare
# per-sweep row would excuse that sweep from the NEXT mechanism too — the one
# nobody has looked at — which is exactly the `DOCS_GATE_KNOWN_EXTRA` asymmetry
# one file over: NAMES, never `=1`. Issue 824 exists because `pin_row_exempt`
# landed in 16 of 19 sweeps and a close-out said "16" instead of gating it.
#
# Deliberately EMPTY, and both mechanisms have the same argument for staying so:
#   - every sweep in the family reads the WORKING TREE, so every one has the
#     Issue-797 exposure; a row would say "this sweep may report a finding no
#     commit contains, and that is fine".
#   - every sweep adjudicates PER-REPO PINS, so every one can hard-red on a
#     repo the contract does not claim; a row would say "this sweep may fail
#     over a repo nobody owns, with zero content findings, and that is fine".
#   - every sweep reads a WORKTREE and compares counts to a tracked ceiling, so
#     every one can count a row that sits on a line no commit contains; a row
#     would say "this sweep may red on another session's in-flight edit, and
#     the reader may re-pin from it". The fan-out reached 19 of 19 before this
#     mechanism was registered, deliberately: a registry row added over unwired
#     sweeps reds the docs gate on develop, and pinning them meanwhile is a
#     backlog wearing a pin (Issue 785).
