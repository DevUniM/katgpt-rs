# Pins for scripts/global_rng_gate.py — Issue 809 T2 + T3.
#
# Every live unseeded-global site in a tracked `*.rs` carries a row here with
# a REASON: free-function global draws (`fastrand::f32()` et al, T1 census
# 2026-09-16) AND unseeded constructors (`Rng::new()` / `Rng::default()`, T3
# census 2026-09-16, key `new`). The commit that adds a site reds until it is
# adjudicated; a row whose site is gone or whose (file, call) count moved reds
# STALE — this file must not only ever loosen.
#
# Format: `relpath::call::count # reason`. Reasonless rows are REFUSED.
# The key is line-free; the count is scoped to the (file, call) pair.
#
# Out of population (documented in the gate's header, not pinned here):
# `fastrand::Rng::with_seed(..)` (the correct pattern) and non-fastrand RNG
# crates.
#
# The DEFECT instances were FIXED, not pinned — they are the reason the gate
# exists: T1 `vocab_channel_pruner` discover_channel/optimize_householder +
# the `bench_pflash_maxsim_block_scoring` fixture pair; T3 `lsh_cache` (the
# SimHash projection now derives from the configuration),
# `bt_fit_from_fn` (takes a seed parameter), and `peira`'s entropy-driven
# convergence test (`with_seed(42)`).
